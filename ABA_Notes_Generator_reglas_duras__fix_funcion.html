Google Drive Sync — Setup Guide
⚠ Requirement: The app must be served from an HTTP URL, not opened as a local file. The quickest option is to host it free on Netlify (drag-and-drop, 2 minutes) or GitHub Pages.
Step 1 — Host the app (if not already)
Go to netlify.com → Log in → Drag your HTML file into the deploy area. Netlify gives you a URL like https://your-app.netlify.app. Bookmark that URL on all your devices.
Step 2 — Create a Google Cloud project
Go to console.cloud.google.com → Create a new project (name it anything, e.g. "ABA Notes") → In the left menu go to APIs & Services → Library → Search for "Google Drive API" → Enable it.
Step 3 — Create OAuth credentials
APIs & Services → Credentials → Create Credentials → OAuth client ID → Application type: Web application → Under "Authorized JavaScript origins" add your Netlify URL (e.g. https://your-app.netlify.app) → Click Create → Copy the Client ID.
Step 4 — Configure OAuth consent screen
APIs & Services → OAuth consent screen → User type: External → Fill in app name (e.g. "ABA Clinical Notes") and your email → Save → Add scope: https://www.googleapis.com/auth/drive.file → Add your email as a test user.
Step 5 — Connect in the app
Paste the Client ID into the field in the app → Click Save → Click "Connect Google Drive" → Sign in with your Google account → Done. All devices where you open the hosted URL and click Connect will share the same client data automatically.
